# Практична робота №2 — Варіант 1

Готовий Angular-застосунок **«Каталог фільмів»**.

Реалізовано всі вимоги із завдання:
- масив із 3 початкових фільмів;
- `*ngFor`;
- interpolation `{{ }}`;
- форма з 3 полями;
- `[(ngModel)]`;
- `(click)`;
- перевірка порожньої назви;
- очищення форми після додавання;
- `*ngIf`;
- `ngClass`;
- `[disabled]`;
- видалення фільмів;
- автоматичний лічильник.

## Як запустити

1. Встановіть Node.js.
2. Відкрийте цю папку в VS Code.
3. У терміналі виконайте:

```bash
npm install
npm start
```

4. Відкрийте адресу, яку покаже Angular CLI (зазвичай http://localhost:4200).
